# Учебный интернет-магазин (ShopProject)

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Многостраничный HTML/CSS-сайт учебного интернет-магазина игровой периферии (клавиатуры, мыши, гарнитуры).
Дисциплина «Фронтенд и бэкенд разработка». Проект сделан без CSS-фреймворков; JavaScript используется только
для модального окна, проверки форм и уведомления об отправке.

## Как посмотреть проект

1. Открыть ссылку GitHub Pages или скачать репозиторий и открыть `index.html` в браузере (сервер не нужен).
2. Пройти по меню: Главная → Каталог → Товар → Заявка → Контакты.
3. Проверить якорные ссылки: блок «Разделы страницы» на главной и ссылки в подвале каждой страницы.
4. В каталоге открыть карточки первых трёх товаров («Подробнее»): `product.html`, `product-2.html`, `product-3.html`.
5. На главной нажать «Заказать» у товара: откроется модальное окно `<dialog>` с выбранным товаром.
6. Отправить форму с пустыми полями (появятся тексты ошибок под полями), затем с корректными данными (появится уведомление).



## Страницы

| Страница | Содержимое 

| `index.html` | hero-блок, ссылки на разделы, преимущества, популярные товары, модальное окно заявки |
| `catalog.html` | 6 карточек с фото, хлебные крошки, `aside` с фильтрами (категории и цена, статическая разметка) |
| `product.html`, `product-2.html`, `product-3.html` | фото, описание, цена, таблица характеристик, другие товары, `aside` с доставкой |
| `order.html` | форма заявки (с выбором товара), `aside` с описанием шагов |
| `contacts.html` | контактная информация, ссылка на форму заявки |

На каждой странице: уникальные `title` и `meta description`, общая навигация, общий CSS, один `main`.

## Используемые технологии

- HTML5 (семантическая разметка: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`);
- CSS3 (переменные, Flexbox, Grid, позиционирование, БЭМ);
- JavaScript (минимально: `<dialog>`, проверка форм, уведомление);
- Git, GitHub, GitHub Pages.

## CSS

- **Переменные** в `:root`: цвета, отступы, скругления, размеры шрифтов, ширина контейнера, слои `z-index`.
- **Состояния:** `:hover`, `:focus-visible`, `:disabled`, подсветка ошибок через `aria-invalid`.
- **Flexbox:** меню, подвал, кнопки, внутренняя структура карточек.
- **Grid:** сетка карточек, раскладка каталога (фильтры + товары), карточка товара, страница заявки.
- **БЭМ:** `site-header`, `site-nav`, `breadcrumbs`, `anchor-nav`, `hero`, `products-grid`, `product-card`,
  `catalog-layout`, `catalog-filters`, `product-page`, `product-table`, `order-layout`, `order-dialog`, `order-form`,
  `button`, `site-footer`, `success-message`, `to-top`. Модификаторы: `product-card--featured`, `--new`, `--discount`,
  `product-page__badge--new`, `site-nav__link--active`.

## Позиционирование

| Свойство | Где используется |
| --- | --- |
| `position: relative` | `.product-card`, `.product-page__media`: контейнеры для бейджей |
| `position: absolute` | `.product-card__badge`, `.product-page__badge`: бейджи "Хит", "Новинка", "Скидка" |
| `position: sticky` | `.site-header` (шапка), `.catalog-filters` (фильтры каталога) |
| `position: fixed` | `.to-top` (кнопка «Наверх»), `.success-message` (уведомление об отправке) |
| `z-index` | шапка, кнопка «Наверх», уведомление, модальное окно (значения заданы переменными) |

Модальное окно `<dialog>` открывается через `showModal()` и попадает в top layer браузера, поэтому
его `z-index` работает как запасной вариант.

## Самостоятельные доработки

Сверх пошаговых методических указаний выполнено:

1. **Каталог из 6 товаров с фото** (клавиатуры, мыши, гарнитуры) и **3 отдельные страницы товаров** с разными
   характеристиками: `product.html`, `product-2.html`, `product-3.html`. Товары 4-6 ведут на форму заявки.
2. **Карточки товаров:** фото, бейджи «Хит», «Новинка», «Скидка» через БЭМ-модификаторы, старая цена у товара со
   скидкой, две кнопки на главной («Подробнее» и «Заказать»).
3. **Навигация:** меню сведено к 5 страницам; якоря вынесены в блок `anchor-nav` на главной и в подвал;
   хлебные крошки на всех внутренних страницах; блок «Другие товары» на карточках; sticky-фильтры.
4. **Фильтры каталога:** категории сделаны переключателями (`radio`), так как выбирается одна категория.
5. **Форма и модальное окно:** название выбранного товара показывается в окне, тема «Заказ товара» подставляется
   автоматически, окно закрывается по клику на фон; на странице заявки добавлен выбор товара.
6. **Доступность:** видимый `:focus-visible`, подписи `label` у всех полей, `aria-current`, `aria-invalid`,
   `aria-describedby` для ошибок, `scope` в таблице, описательные `alt` у фото, отступ `scroll-margin-top`
   под липкой шапкой
7. **Структура CSS:** убраны дубли правил, повторяющиеся значения вынесены в переменные
